The dataset containing order details, product categories, customer information, payment methods, delivery details, ratings, and revenue was stored and analyzed using MySQL.
SQL queries were developed to retrieve, filter, sort, and summarize data. 
Aggregate functions were used to calculate important metrics such as total revenue, average ratings, and sales quantity. 
Grouping techniques helped analyze sales based on product categories and regions.
Joins were applied to combine customer and sales information, while subqueries were used for advanced analysis. 
Views were created for reusable reports, and indexes were implemented to improve query efficiency.
The project highlights the importance of SQL in handling structured data, performing analytical operations, and generating valuable insights for data-driven decision-making.
