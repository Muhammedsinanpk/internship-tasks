E-Commerce Return Analysis & Prediction
📌 Overview

An end-to-end E-Commerce Data Analytics and Machine Learning project focused on analyzing customer orders, identifying return patterns, predicting order returns, and generating business insights.

🛠️ Tools Used
Python & Jupyter Notebook
Pandas, NumPy, Matplotlib, Seaborn
Scikit-learn
MySQL Workbench
Power BI

🔍 Project Includes
Data Cleaning & Preprocessing
Exploratory Data Analysis (EDA)
SQL Business Analysis
Machine Learning for Return Prediction
Model Evaluation
Interactive Power BI Dashboard
Business Insights & Recommendations
📂 Project Files

The complete project is uploaded as a ZIP file.

Download the ZIP → Extract it → All datasets, notebooks, SQL files, Power BI files, and project resources will be available inside.

📊 Dataset

Kaggle E-Commerce Dataset containing order, customer, product, payment, delivery, return, and financial information.
