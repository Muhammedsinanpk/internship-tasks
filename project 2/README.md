# Healthcare Appointment No-Show Prediction

A data science and machine learning project that analyzes healthcare appointment data and predicts whether a patient is likely to miss a scheduled appointment.

## Project Overview

The project includes:

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Feature engineering
* Machine Learning using Decision Tree
* No-show probability and risk classification
* Interactive Power BI dashboard

The dataset contains **110,527 records and 14 variables**, including patient demographics, medical conditions, appointment details, SMS reminders, and neighbourhood information.

## Model Performance

* **Model:** Decision Tree Classifier
* **Accuracy:** 79.81%
* **ROC-AUC:** 0.721
* **No-show Rate:** 20.19%

The model predictions were also converted into **Low, Medium, and High Risk** categories.
